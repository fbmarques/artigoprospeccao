# Material suplementar – Metodologias de prospecção tecnológica baseadas em dados documentais: uma revisão integrativa (2020–2026)

Este repositório reúne os dados que sustentam a síntese apresentada no artigo. Os textos completos dos estudos não são disponibilizados, pois foram obtidos pelo Portal de Periódicos da CAPES, cujas normas restringem o uso a usuários autorizados e a fins pessoais, de ensino e de pesquisa.

## Conteúdo

| Pasta/arquivo | Descrição |
| --- | --- |
| `dados/estudos_incluidos.csv` | Os 108 estudos incluídos, com todas as classificações (tipo de abordagem, finalidade, técnicas, fontes, bases, ferramentas, validação, transparência, transferibilidade a software) e os campos principais da extração. Separador: ponto e vírgula; codificação UTF-8. |
| `dados/registro_decisoes_selecao.csv` | Os 786 registros triados, com as decisões e os motivos de exclusão de cada rodada, as sugestões geradas pela IA (2ª e 3ª rodadas) e a decisão no texto completo. |
| `dados/avaliacao_critica.csv` | Avaliação crítica dos 95 estudos primários: 10 critérios (Sim, Parcial, Não, NI), código e dados disponíveis, pontuação e classificação. |
| `dados/reclassificacao_cega_amostra20.csv` | Reclassificação cega de 20 estudos sorteados (semente 20261026), usada no cálculo de concordância. |
| `dados/confiabilidade_classificacao.csv` | Todas as classificações alteradas após a resolução das divergências e a reconferência dirigida, com valor original e final. |
| `dados/teste_sensibilidade_busca.csv` | Conjunto de referência de 28 artigos citados por três revisões incluídas e sua recuperação pelas buscas original e complementar. |
| `dados/busca_complementar_pre_triagem.xlsx` | Os 293 registros da busca complementar, com pré-triagem por título (não incorporados à síntese). |
| `dados/dados_revisao.xlsx` | Os arquivos de dados acima em uma única planilha. |
| `documentacao/definicoes_categorias.md` | Definição de todas as categorias e da regra de predominância. |
| `documentacao/dicionario_codificacao.csv` | Expressões regulares usadas na codificação automática de técnicas, fontes, bases e ferramentas. |
| `documentacao/protocolo_e_busca.md` | Protocolo, emendas, uso de IA, estratégias de busca completas e fluxo de seleção. |
| `figuras/` | Figuras do artigo em 600 dpi. |

## Códigos

`ID` (R001–R786) identifica cada registro após a remoção de duplicados e é o mesmo em todos os arquivos.
